# Music_System

## Descripción General
Este proyecto es un sistema interactivo de gestión de música en consola desarrollado en **C++** como proyecto integrador del curso virtual bootcamp *Programación de Cero a POO*. Permite administrar un catálogo de hasta 20 canciones guardando su nombre, artista y número de reproducciones en YouTube.

## Funcionalidades del Menú

1. **Registrar una canción:** Solicita al usuario ingresar el nombre de la canción, el autor y la cantidad de visitas en YouTube, almacenándolos en el sistema en un máximo de 20 canciones
2. **Mostrar los registros de canciones:** Despliega una lista con todas las canciones registradas hasta el momento.
3. **Buscar una canción:** Permite ingresar el nombre de una canción para verificar si existe en el catálogo y mostrar su información.
4. **Mostrar reporte general:** Calcula y muestra estadísticas acumuladas del catálogo, como:
   - Total de canciones registradas.
   - Suma total de visitas acumuladas.
   - Promedio de reproducciones por canción.
   - Canción más popular del catálogo.
5. **Playlist para barrer la casa como señora despechada / alma depresiva:** Filtra automáticamente el catálogo y genera una lista especial mostrando únicamente los "hits" más populares que superan **1,000,000 de reproducciones** en YouTube.
6. **Salir:** Finaliza la ejecución del programa.

## Componente Creativo
El toque creativo del proyecto es la función **"Playlist para barrer la casa como señora despechada / alma depresiva"** (Opción 5). Esta opción actúa como un filtro automático "generador de hits" que selecciona únicamente las canciones más escuchadas del catálogo con más de 1 millón de visitas en YouTube
